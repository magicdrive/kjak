Usage:
  kjak feather list [-o text|json]
  kjak feather show NAME [-o text|json]
  kjak feather add NAME --type os|slack|discord|email [options]
  kjak feather remove NAME [--scope global|project]
  kjak feather enable NAME [--scope global|project]
  kjak feather disable NAME [--scope global|project]
  kjak feather types
  kjak feather plugins [-o text|json]

A feather is one notification destination. An http feather (any HTTP API)
and an external feather (a plugin, kjak-feather-<name> on PATH) are written
in the configuration file: see docs/http.md and docs/plugins.md. `plugins`
lists the plugins of PATH; it runs none of them.

Options of add:
      --type TYPE              os, slack, discord or email (required)
  -s, --scope SCOPE            global (default) or project
      --force                  Replace a feather of the same name
      --disabled               Add it disabled
      --levels L[,L]           Accept only these levels (default: all)

  The secret (webhook_url of slack and discord, password of email; an os
  feather has none), one of:
      --secret-env VAR         Read it from the environment variable VAR
      --secret-keychain S/A    Read it from the OS keychain (service/account)
      --secret-ref NAME        Read it from a secrets file (kjak config --help)
      --secret-stdin           Store it in the file, read from standard input
                               (a literal: deprecated)

  discord:
      --username NAME          Display name of the messages
  email:
      --host HOST              SMTP server (required)
      --port PORT              Default 587 (starttls), 465 (tls), 25 (none)
      --security MODE          starttls (default), tls or none
      --user USER              SMTP user (with a password secret)
      --from ADDRESS           Sender (required)
      --mail-to ADDRESS[,..]   Recipients (required, repeatable)
      --subject-prefix TEXT    Prefix of every subject

Common options:
  -c, --config FILE            The global configuration file
      --secrets FILE           The personal secrets file
      --no-project             Ignore ./.kjak.toml
  -h, --help                   Show this help

Without --scope, remove, enable and disable change the file that defines the
feather. A project file is changed only when it is trusted.

Examples:
  kjak feather add desktop --type os
  kjak feather add dev_slack --type slack --secret-env KJAK_DEV_SLACK_WEBHOOK
  kjak feather add ops_mail --type email --host smtp.example.com \
      --user kjak@example.com --secret-keychain kjak/ops_mail \
      --from kjak@example.com --mail-to oncall@example.com
